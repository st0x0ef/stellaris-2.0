The Fuel Refinery is a machine used to refine [ref=stellaris:items/oil]oil[ref].

[image=stellaris:textures/wiki/rendered_blocks/fuel_refinery width=96 height=96]



How to use : 
Place the fuel refinery next to an electricity source. Then you can input oil that will be refined into fuel and diesel. 

Stats : 
- Power Consumption : 100 FE/t 
- Oil Consumption : 1000 mB/t 
- Fuel Production : 500 mB/t 
- Diesel Production : 500 mB/t
