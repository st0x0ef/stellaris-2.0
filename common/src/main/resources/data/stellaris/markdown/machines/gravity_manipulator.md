The Gravity Manipulator is a machine that can be used to manipulate gravity in a specific chunk. It is commonly used in space stations and other structures to create a comfortable environment for inhabitants.

[image=stellaris:textures/wiki/rendered_blocks/gravity_manipulator width=96 height=96]



How to use : 
Place the Gravity Manipulator in the desired chunk. Connect the machine to a power source, then open the GUI to select the desired gravity level. The machine will then adjust the gravity in the chunk accordingly.

[image=stellaris:textures/wiki/gui/gravity_manipulator_gui width=145 height=96]



Stats : 
- Power Consumption : 1 FE/t
