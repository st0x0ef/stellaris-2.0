This is a Parasite Villager. Scientists have discovered that the [ref=stellaris:mobs/parasite]parasite[ref] transforms regular villagers into this creature.

This alien is pretty passive unless you attack it. 
But beware! Scientists have discovered that after some time they evolve into an [ref=stellaris:mobs/evolved_parasite_villager]Evolved Parasite Villager[ref].
