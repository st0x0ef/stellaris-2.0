The Geiger Counter can tell you if there is radiation around.

[item=stellaris:geiger_counter_tier_1]

**Right-click** anywhere to use it.

You can change the working radius by punching a block. If you are shifting, the radius will decrease. If not, it will increase.

**Right-click** while shifting to cycle between the different mode :

- **Total Radiation** : tell you the total amount of radiation around you.
- **Max Radiation** : tell you what is the most radioactive block
